
# Model Development Notebooks

This folder contains the Google Colab Jupyter notebooks (`.ipynb`) used for data preprocessing, model development, training, experimentation, and evaluation.

The notebooks cover the implementation of Windowed 1D CNN, Attention-MIL CNN, and Mamba-2 model variants for exoplanet vetting using Kepler light curves.
